# 拾词 · Wordnote

一个纯本地的极简单词本。无需安装、无需联网、无需登录，打开 `index.html` 就能使用。

所有单词与学习记录都保存在当前浏览器的 `localStorage` 中，并带有自动备份、JSON 导入导出和 CSV/TXT 导入。

## 快速开始

1. 双击 `index.html`，用 Edge、Chrome 或其他现代浏览器打开。
2. 点击「添加单词」记录第一个词，或在空词库页面点击「载入示例词库」。
3. 回到「今日学习」开始背单词；也可以随时做一组测验。
4. 建议定期在「设置 → 数据管理」导出 JSON 备份。

> 应用没有构建步骤。修改 HTML/CSS/JS 后刷新页面即可生效。

## 功能

### 单词管理

- 单词、音标、多条词性/释义、多个例句与翻译、标签、笔记、重点标记。
- 自动检查重复单词。
- 搜索单词、音标、释义、例句、标签和笔记。
- 按待复习、新词、学习中、已掌握、重点、易错筛选，按标签筛选。
- 支持按最近添加、字母顺序、复习时间、错误次数排序。
- 批量加标签、标记掌握、重置进度、删除。
- 支持朗读单词（依赖浏览器自带语音引擎）。

### 背单词

- 今日学习：自动混合到期复习词和未学习的新词。
- 自由练习：从词库随机抽取最多 30 个词。
- 易错专项：只练习有错误记录的词。
- 四档评分：忘记 / 模糊 / 记住 / 简单。
- 简化版 SM-2 间隔重复算法，自动安排下一次复习时间。
- 选择「忘记」的词会在本轮稍后再次出现，最多加练两次。
- 学习结束后展示本轮词数、新词数、正确率、忘记数量和用时。

### 测验

- 混合、英译中、中译英、拼写、听写五种模式。
- 范围可选全部、待复习、易错词、重点词。
- 题量可选 10 题、20 题或全部。
- 测验结果可选择同步到间隔重复计划。
- 支持重练错题、再来一组。
- 听写模式使用浏览器语音朗读，是否可用取决于系统语音。

### 统计

- 连续打卡天数、近 30 天学习词数、已掌握词数、近 30 天正确率。
- 近 30 天学习热力图，以及今日/近 7 天/目标达成天数。
- 掌握情况环图：已掌握、学习中、新词。
- 近 7 天学习量柱状图。
- 易错词排行与专项练习入口。

### 设置与数据

- 每日目标词数、每日新词上限、单次复习上限。
- 卡片自动发音、测验同步复习进度。
- 跟随系统 / 浅色 / 深色主题。
- 选择语音、调整语速、试听发音。
- 导出 JSON 完整备份、导出 CSV、导入 JSON/CSV/TXT。
- 每日自动备份与手动恢复。
- 一键清空全部数据（清空前会自动保存一份备份）。

## 数据保存在哪里

| 内容 | localStorage 键名 |
| --- | --- |
| 当前全部数据 | `shici.v1` |
| 自动备份 | `shici.backup.v1` |

注意：

- 数据只存在当前浏览器、当前浏览器配置文件中，不会自动同步到手机或其他电脑。
- 清除浏览器站点数据、使用无痕模式、重装系统或更换浏览器，都可能导致数据丢失。
- 通过 `file://` 打开时，数据与浏览器对本地文件的存储策略有关。移动文件夹或改名之前，建议先导出 JSON 备份。
- 想要长期保存，最稳妥的方式是定期导出 JSON，并把文件放到网盘或其他安全位置。
- 换设备时，在新设备打开应用，进入「设置 → 数据管理 → 导入文件」，选择 JSON 备份即可。

## 导入格式

### JSON

支持两种 JSON：

1. 应用导出的完整备份（包含 `words`、`logs`、`settings` 等字段）。导入时可选择「合并单词」或「覆盖恢复」。
2. 单词对象数组，例如：

```json
[
  {
    "term": "serendipity",
    "phonetic": "/ˌserənˈdɪpəti/",
    "meanings": [{ "pos": "n.", "def": "意外发现美好事物的运气" }],
    "examples": [
      {
        "text": "Meeting her was pure serendipity.",
        "translation": "遇见她纯属美妙的机缘。"
      }
    ],
    "tags": ["高阶", "生活"],
    "note": "值得记住的词"
  }
]
```

导入时重复的单词会自动跳过，已有单词的学习进度不会被覆盖。

### CSV

推荐使用 UTF-8 编码，第一行写表头。表头顺序不限，以下列名均可识别（中英文皆可）：

```csv
单词,音标,词性,释义,例句,例句翻译,标签,备注
serendipity,/ˌserənˈdɪpəti/,n.,意外发现美好事物的运气,Meeting her was pure serendipity.,遇见她纯属美妙的机缘。,"高阶, 生活",值得记住的词
```

也支持这些常见别名：

- 单词：`word`、`term`、`英文`、`词汇`
- 音标：`phonetic`、`ipa`、`pronunciation`
- 词性：`pos`、`part of speech`
- 释义：`meaning`、`definition`、`def`、`中文`、`意思`
- 例句：`example`、`sentence`
- 例句翻译：`example translation`、`例句中文`
- 标签：`tags`、`tag`、`分类`
- 备注：`note`、`notes`、`memo`

如果需要多个例句，可在单元格中用 `|` 分隔。标签可用逗号、中文逗号、顿号、分号或斜杠分隔。

没有表头时，默认按以下列顺序解析：

```text
单词, 释义, 音标, 例句, 例句翻译, 标签, 备注
```

### TXT

每行一个单词，支持：

```text
serendipity	意外发现美好事物的运气
resilient	有韧性的；能迅速恢复的
ephemeral - 短暂的；转瞬即逝的
```

- 使用 Tab 分隔单词与释义，也支持 `单词 - 释义` 或 `单词, 释义`。
- 以 `#` 开头的行会被忽略。

## 快捷键

| 键 | 功能 |
| --- | --- |
| `N` | 新建单词（不在输入框或弹窗中时） |
| `/` | 跳转到单词库并聚焦搜索框 |
| `Space` | 学习时翻面 |
| `1` `2` `3` `4` | 学习时评分；测验时选择选项 |
| `S` | 朗读当前单词 |
| `Enter` | 测验中继续下一题 |
| `Esc` | 退出学习/测验，或关闭弹窗 |

## 浏览器建议

- 推荐最新版 Microsoft Edge 或 Google Chrome。
- 发音功能依赖 `speechSynthesis` 和系统安装的英语语音；如果「语音」下拉框为空或无法朗读，请检查系统语音包。
- 深色主题可以手动切换，也可以在设置中选择「跟随系统」。
- 应用包含移动端底部导航和响应式布局，可直接在手机浏览器中打开，但数据仍只保存在该手机浏览器里。

## 常见问题

**为什么刷新后数据还在，但换浏览器就没了？**

`localStorage` 按浏览器隔离。换浏览器或换设备需要使用 JSON 备份迁移。

**为什么「今日学习」显示没有待复习的词？**

说明当前没有到期词，且新词额度已用完或词库中没有新词。可以点「自由练习」或「做测验」。

**自动备份什么时候发生？**

应用启动时，如果当天还没有备份，会自动保存一份。清空数据、覆盖导入等危险操作前也会额外保存。

**恢复备份会覆盖当前数据吗？**

会。恢复前会先把当前数据保存到备份区，但建议在恢复前手动导出一份 JSON。

**能同步到云端吗？**

这个版本不包含云同步或账号系统，所有数据都留在本机。可以通过导出 JSON 到网盘来手动备份。
